OPENING THE WEBSITE
-------------------
Open index.html in a modern browser. All site pages link to shared CSS and
JavaScript using relative paths, so the project can also be hosted as a static
site. Internet access is needed for the remote Unsplash photographs, the Mixkit
mountain-climbing homepage video, and Google Fonts. The home hero uses a still
image when its video is unavailable or reduced motion is enabled. If offline use
is required,
download properly licensed replacement media into images/ and update the URLs.

FEATURES
--------
- Eight core pages and four individual destination guides.
- Responsive navigation, page-specific active navigation, and shared footer.
- Looping muted mountain video on the home hero, with a still-image fallback.
- Destination category filters and live search.
- Adventure activity detail disclosures and seasonal travel guide accordions.
- Gallery category filters and keyboard-operable photo lightbox.
- Browser-native validation and demo success messages for forms.
- Accessible labels, alt text, skip link, focus styles, and reduced-motion support.

DEMO LIMITATIONS
----------------
This is a static educational E-Project, not a travel operator. Package prices,
contact details, team identities, and testimonials are illustrative placeholders.
Forms validate locally and show a demo confirmation; they do not send, process,
or store submissions and do not make real reservations. Replace placeholder
social links and contact details before any public presentation. Always verify
current travel, weather, road, permit, and safety information through trusted
local sources before a real trip.

TECHNOLOGIES
------------
HTML5, CSS3 and vanilla JavaScript only. No build process or packages required.
